# Exercício módulo 7 — Comparação de números

Lê dois números inteiros e informa qual é o maior ou se são iguais.

## Conceitos praticados

Condicionais e leitura de dados com Scanner.

## Como executar

1. Abra a pasta do projeto no IntelliJ IDEA.
2. Configure um JDK 17 ou superior.
3. Execute o método main da classe Main.
